## demo.mp4 (16:9, under 60 seconds, H.264)

Used by: the "Sixty seconds, end to end" section. The section stays hidden
until this file exists and loads.

The strongest version is a screen recording of the real product, not a
generated film. Suggested storyboard, about 50 seconds:

1. 0-8s: the homepage, scroll past the scanner demo.
2. 8-20s: sign in, land on Coverage, the meters fill.
3. 20-35s: Add warranty, photograph a receipt, watch the fields fill themselves.
4. 35-50s: open a record, start a claim, the drafted letter appears. End on the
   letter.

Record at 1920x1080, trim silence, no background music needed.
